The only button in Year Strong. One `primary` per screen — it is the thing you came to do.

```jsx
<Button size="lg" block onClick={logSet}>LOG SET</Button>
<Button variant="plain" onClick={skip}>Skip today</Button>
```

Primary CTA copy is ALL CAPS in Gluten (`LOG SET`). Secondary actions are sentence case. Never put two primaries side by side — use `quiet` for the other one.
